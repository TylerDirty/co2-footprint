# CO₂ Footprint – Webanwendung zur Darstellung von Emissionsdaten

Diese Webanwendung wurde im Rahmen einer Fallstudie im Modul Webentwicklung an der IU Internationalen Hochschule erstellt. Ziel ist die übersichtliche Darstellung fiktiver CO₂-Emissionsdaten von Ländern und Unternehmen mit Filter- und Sortierfunktion.

## Funktionen

* Anzeige einer CO₂-Emissionsdatentabelle
* Filter nach Land oder Unternehmen
* Sortierung nach Land, Unternehmen und Emissionswert
* Responsives Layout mit Bootstrap
* Anpassung des lokalen Navigationsmenüs an Schriftkulturen (LTR / RTL)

## Verwendete Technologien

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## Nutzung

Repository herunterladen und die Datei **index.html** im Browser öffnen.

## Hinweis

Alle dargestellten Daten sind fiktiv und dienen ausschließlich Demonstrationszwecken im Rahmen der Fallstudie.
